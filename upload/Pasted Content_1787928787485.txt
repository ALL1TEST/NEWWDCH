1. PLATFORM ROLES
==================================================

Define clear roles:

OWNER
PLATFORM_ADMIN
CLIENT

OWNER:
- Full platform control
- Can manage plans
- Can manage pricing
- Can manage feature access
- Can manage customers
- Can manage subscriptions
- Can manage coupons
- Can manage email/SMTP
- Can manage backups
- Can manage platform settings
- Can manage platform admins
- Can access all sites if necessary
- Has billing bypass for internal use

PLATFORM_ADMIN:
- Platform management according to permissions
- Customer management
- Subscription/payment management
- Usage monitoring
- Support/admin operations
- No access to highly sensitive owner-only settings unless explicitly granted

CLIENT:
- Only their own account and resources
- Only features allowed by their subscription/entitlements

IMPORTANT:
Do not rely on hiding UI elements for authorization.

Every protected admin route and backend/API action must be authorized server-side.
